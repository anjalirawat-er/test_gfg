<h2><a href="https://www.geeksforgeeks.org/problems/gray-code-1587115620/1">Binary To Gray Code Conversion</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given a non-negative integer <strong>n</strong>, convert its binary representation into the corresponding Gray code and return the decimal value of the resulting Gray code.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>n = 7
<strong>Output</strong>: 4
<strong>Explanation</strong>: The binary representation of 7 is 111. Its Gray code representation is 100, whose decimal value is 4.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>n = 10
<strong>Output</strong>: 15
<strong>Explanation</strong>: </span><span style="font-size: 18px;">The binary representation of 10 is 1010. Its Gray code representation is 1111, whose decimal value is 15.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>n = 0
<strong>Output</strong>: 0
<strong>Explanation</strong>: The binary representation of 0 is 0. Its Gray code representation is also 0, whose decimal value is 0.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>0 ≤ n ≤ 10<sup>9</sup></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Bit Magic</code>&nbsp;
