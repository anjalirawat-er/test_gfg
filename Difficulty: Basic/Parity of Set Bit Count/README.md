<h2><a href="https://www.geeksforgeeks.org/problems/parity-of-unsigned-integer4247/1">Parity of Set Bit Count</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given an integer <strong>n</strong>, determine parity of set bit count.</span></p>
<ul>
<li><span style="font-size: 14pt;">The number has even parity if it contains an even number of set bits.</span></li>
<li><span style="font-size: 14pt;">The number has odd parity if it contains an odd number of set bits.</span></li>
</ul>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> n<strong> = </strong>13
<strong>Output: </strong>"odd"
<strong>Explanation: </strong>(13)<sub>10</sub> = (1101)<sub>2</sub>  binary representation has three 1-bits , parity is "odd".</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>n <strong>= </strong>9
<strong>Output: </strong>"even"
<strong>Explanation: </strong>(9)<sub>10</sub> = (1001)<sub>2</sub>  binary representation has two 1-bits , parity is "even".</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Mathematics</code>&nbsp;<code>Bit Magic</code>&nbsp;
